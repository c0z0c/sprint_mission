## B7 DataFrame 변환 예시

### 입력 (원본)

```python
df_original = pd.DataFrame({
    'Test_id': ['0x744773A3...'],
    'B7': ['1,1,1,1,1,2,1,1,1,1,1,1,1,2,2']  # 15개 값만
})
```

---

## 문제점 분석

### **심각한 데이터 부족**

**정상 B7 구조**:
```python
B7-1: 자극 타입 (24개)
B7-2: 응답 (24개)
B7-3: 정답여부 (24개)
B7-4: 반응시간 (24개)
```

**현재 데이터**:
```python
B7: 단일 컬럼 15개 값만
```

→ **24개 중 15개만 존재** (37.5% 누락)
→ **컬럼 구분 없음** (B7-1/2/3/4 중 어느 것인지 불명)

---

## 가능한 해석

### **가정 1: B7-1 (자극 타입)만 제공**

```python
# 입력
B7 = [1,1,1,1,1,2,1,1,1,1,1,1,1,2,2]  # 15개 자극타입

# 값 1 = 홀짝 판단 (12개)
# 값 2 = 대소 비교 (3개)

# 출력 (매우 제한적)
df_features = pd.DataFrame({
    'Test_id': ['0x744773A3...'],
    
    # 자극 분포만 계산 가능
    'B7_oddeven_count': [12],    # 타입1
    'B7_compare_count': [3],     # 타입2
    'B7_total_trials': [15],     # 15개만 (정상 24개)
    'B7_oddeven_ratio': [0.80],  # 12/15
    'B7_compare_ratio': [0.20],  # 3/15
    
    # 전환 횟수 추정
    'B7_switch_count': [2],      # 1→2 또는 2→1 전환
    
    # 나머지는 계산 불가
    'B7_accuracy': [None],
    'B7_rt_mean': [None],
    'B7_switch_cost_rt': [None]  # ★핵심 지표 계산 불가★
})
```

### **계산**

```python
values = [1,1,1,1,1,2,1,1,1,1,1,1,1,2,2]

# 타입별 카운트
type1_count = values.count(1) = 12  # 홀짝 판단
type2_count = values.count(2) = 3   # 대소 비교
total = 15

# 전환 횟수 계산
switches = 0
for i in range(1, len(values)):
    if values[i] != values[i-1]:
        switches += 1

switches = 2  # [5→6: 1→2], [13→14: 1→2]
```

## 결론: **핵심 분석 불가능**

### **치명적 누락 정보**

1. **반응시간 없음** (B7-4):
   - switch_cost_rt 계산 불가 ★★★
   - B7의 가장 중요한 지표 누락

2. **컬럼 구분 없음**:
   - 자극/응답/정답 구분 불가
   - 어떤 의미인지 불명확

3. **Trials 부족**:
   - 24개 중 15개만 (62.5%)
   - 전환 패턴 불완전

4. **A7 비교 불가**:
   - Switch cost 비교 불가 ★★★
   - 주의 전환 능력 변화 평가 불가

## 권장사항

**1. 데이터 확인 필수**:
- B7-1, B7-2, B7-3, B7-4 전체 컬럼 확인
- 24개 trials 완전한 데이터 필요
- 특히 B7-4 (반응시간) 필수 ★★★

**2. 현재 데이터로는**:
- 주의 전환 능력 평가 불가
- A7과 비교 불가
- 머신러닝 피처로 부적합

**3. 대안**:
- 결측치로 처리 권장
- 또는 자극 분포만 최소 추출
- 하지만 실질적 가치 매우 낮음

**문자열 1개 (15개 값) → 숫자 8개** (핵심 지표 없음, 실용성 매우 낮음)

**→ B7의 핵심인 switch_cost 계산 불가로 인해 이 데이터는 거의 무용지물**
