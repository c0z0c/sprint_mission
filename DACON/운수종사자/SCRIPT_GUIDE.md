## 문제 해결

### 1. 모델 파일을 찾을 수 없음
**증상**: `FileNotFoundError: 모델 파일을 찾을 수 없습니다`

**해결**:
- `model_dir` 경로 확인
- 모델 파일명이 `lightgbm_A_best_*.pkl` 또는 `lightgbm_B_best_*.pkl` 형식인지 확인
- 스크립트는 자동으로 최신 체크포인트를 찾습니다

### 2. 테스트 데이터를 찾을 수 없음
**증상**: `FileNotFoundError: 테스트 데이터를 찾을 수 없습니다`

**해결**:
- `data_dir` 경로 확인
- `test_A_.jsonl`과 `test_B_.jsonl` 파일 존재 확인

### 3. 확률값이 0~1 범위를 벗어남
**증상**: `⚠ Label 값이 0~1 범위를 벗어났습니다!`

**해결**:
- 모델 재학습 필요
- 전처리 과정 확인

## 참고 사항

1. **경로 수정**: Windows 외 환경에서는 `script.py` 내 경로를 수정하세요.
