## A6 DataFrame 변환 예시

### 검사 개요

**A6 검사: 문제풀이식 (판단능력)**
- **측정 요인**: 판단능력, 돌발상황에서 교통정보 파악 능력 (지적운동요인)
- **검사 방식**: 총 14 trials
- **검사 내용**: 제시된 2개 도형의 관계성을 파악하여, 주어진 도형과 관계되는 도형을 찾아 해당 버튼을 누름
- **제한 시간**: 7분

### 입력 (원본)

```python
df_original = pd.DataFrame({
    'Test_id': ['0x744773A3...'],
    'A6-1': ['13']  # 정답 수 (총 14 trials 중)
})
```

### 데이터 컬럼

| 컬럼명 | 내용   | 조건                |
|--------|--------|---------------------|
| A6-1   | 개수   | 정답 수 (총 14 trials 중) |

### 출력 (지수화)

```python
df_features = pd.DataFrame({
    'Test_id': ['0x744773A3...'],
    
    # 정답 수 (1개)
    'A6_correct_count': [13],
    
    # 정답률 (1개)
    'A6_accuracy': [13/14],  # 0.929
    
    # 오답 수 (1개)
    'A6_incorrect_count': [1],
    
    # 정답률 구간 (1개)
    'A6_acc_level': [3]  # 1: 낮음(0-50%), 2: 중간(50-85%), 3: 높음(85-100%)
})
```

### 실제 계산

```python
# 기본 통계
total_trials = 14
correct_count = 13
incorrect_count = 1

# 정답률
accuracy = correct_count / total_trials = 13 / 14 = 0.929

# 정답률 구간 분류
if accuracy >= 0.85:
    acc_level = 3  # 높음
elif accuracy >= 0.50:
    acc_level = 2  # 중간
else:
    acc_level = 1  # 낮음
```

### 정상 vs 위험 패턴

```python
# 정상 케이스
{
    'A6_correct_count': 12,   # 12개 이상 정답
    'A6_accuracy': 0.857,     # 85% 이상
    'A6_acc_level': 3         # 높은 정답률
}

# 경고 케이스
{
    'A6_correct_count': 9,    # 9-11개 정답
    'A6_accuracy': 0.643,     # 50-85%
    'A6_acc_level': 2         # 중간 정답률 ★
}

# 위험 케이스
{
    'A6_correct_count': 6,    # 7개 이하 정답
    'A6_accuracy': 0.429,     # 50% 미만 ★★
    'A6_acc_level': 1         # 낮은 정답률 ★★★
}
```

### 주의사항

- 화면에 제시된 두 그림의 관계를 파악한 이후, 두 도형의 관계와 관계되는 도형을 찾아 해당 버튼을 누름
- 제한시간 7분
- 어려운 문제는 '다음' 버튼을 눌러 건너뛰고, 남은 시간에 풀어도 됨
- 제한시간이 지나면 자동으로 다음 검사로 넘어가기 때문에 제한시간 내에 가능한 많은 문항을 풀어야 함

### 평가 기준

- **정답 수**: 컬럼 A6-1에 기록되는 정답 수
- **판단 능력 평가**: 도형 간 관계성을 파악하는 능력
- **돌발 상황 대응력**: 복잡한 정보를 빠르게 처리하는 능력

**문자열 1개 → 숫자 4개**
