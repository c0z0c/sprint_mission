## A7 검사: 문제풀이식 (단순도형)

### 검사 개요

* **주의사항**: 판단능력, 돌발상황에서 교통정보 파악 능력 (지적운동요인)

* **검사 방식**:
    - 총 18 trials
    - 단순도형을 포함하는 복잡도형 또는 복잡도형에 포함된 단순도형을 찾아 해당 버튼을 누름

### 데이터 컬럼

| 컬럼명 | 내용         | 조건                  |
|--------|--------------|-----------------------|
| A7-1   | 개수 (정답 수) | 총 18 trials 중 정답 개수 |

### 예시 데이터

```python
A7-1: "12"
```

### 평가 기준

- 정답 수
- 컬럼 A7-1에 기록되는 정답 수입니다

### 검사 주의사항

- 어려운 문제는 '다음' 버튼을 눌러 건너뛰고, 남은 시간에 풀어도 됨
- 지각성향검사 도형의 크기와 방향이 같아야 함
- 유념해야할 사항은 검사 중간에 단순도형검사에서 복잡도형검사로 바뀐다는 것입니다

### 단순도형검사와 복잡도형검사

1. **첫번째 유형 - 단순도형검사**: 
   - 왼쪽에 제시된 단순도형 안에 포함되어있는 단순도형을 찾는 문제입니다

2. **두번째 유형 - 복잡도형검사**: 
   - 왼쪽에 제시된 복잡도형 안에 포함되어있는 단순도형을 찾는 문제입니다

### DataFrame 변환 예시

#### 입력 (원본)

```python
df_original = pd.DataFrame({
    'Test_id': ['0x744773A3...'],
    'A7-1': ['12']  # 18 trials 중 정답 12개
})
```

#### 출력 (피처 생성)

```python
df_features = pd.DataFrame({
    'Test_id': ['0x744773A3...'],
    
    # 정답률 피처
    'A7_correct_count': [12],        # 정답 개수
    'A7_accuracy': [12/18],          # 정답률 = 0.667
    'A7_error_count': [6],           # 오답 개수 = 18 - 12
    'A7_error_rate': [6/18],         # 오답률 = 0.333
    
    # 평가 지표
    'A7_performance_level': ['보통'] # 정답률 기준 평가
})
```

### 성능 평가 기준

```python
# 정답률 기준
def evaluate_a7_performance(correct_count, total=18):
    accuracy = correct_count / total
    
    if accuracy >= 0.9:           # 16개 이상
        return '우수', 1
    elif accuracy >= 0.75:        # 14-15개
        return '양호', 2
    elif accuracy >= 0.6:         # 11-13개
        return '보통', 3
    elif accuracy >= 0.5:         # 9-10개
        return '주의', 4
    else:                         # 8개 이하
        return '위험', 5

# 예시
correct = 12
performance, level = evaluate_a7_performance(correct)
print(f"정답: {correct}/18, 정답률: {correct/18:.1%}, 평가: {performance}")
# 출력: 정답: 12/18, 정답률: 66.7%, 평가: 보통
```


### 주요 위험 지표

1. **A7_accuracy < 0.5**: 정답률 50% 미만 (위험) ★★★
2. **A7_accuracy < 0.6**: 정답률 60% 미만 (주의) ★★
3. **A7_error_count > 9**: 오답 10개 이상 (위험) ★★★

### 해석 가이드

- A7 검사는 **지각성향 및 공간 판단력**을 평가합니다
- 복잡한 시각 정보 속에서 필요한 정보를 빠르게 찾아내는 능력 측정
- 낮은 정답률은 **돌발 상황에서의 대처 능력 저하**를 시사할 수 있습니다

**문자열 1개 → 숫자 4개 + 평가 1개**
