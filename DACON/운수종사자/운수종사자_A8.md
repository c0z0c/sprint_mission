## 실제 계산

```python
# 입력
distortion = 7   # A8-1
consistency = 0  # A8-2

# 1. 원점수 (그대로 사용)
A8_distortion_score = 7
A8_consistency_score = 0

# 2. 정규화 (0~1 범위)
# 가정: 점수 범위 0~10
A8_distortion_norm = 7 / 10 = 0.7
A8_consistency_norm = 0 / 10 = 0.0

# 3. 이진 범주화
# 왜곡 높음 (≥7)
A8_distortion_high = 1 if distortion >= 7 else 0
A8_distortion_high = 1

# 일관성 좋음 (≤2)
A8_consistency_good = 1 if consistency <= 2 else 0
A8_consistency_good = 1

# 4. 종합 타당도 점수 계산
# 공식: 1 - (왜곡 * 0.1 + 일관성문제 * 0.15)
A8_validity_score = 1 - (7 * 0.1 + 0 * 0.15)
                  = 1 - 0.7
                  = 0.3

# 5. 검사 신뢰 가능 여부
# 임계값: 0.7
A8_test_reliable = 1 if A8_validity_score >= 0.7 else 0
A8_test_reliable = 0  # 신뢰 불가 ★★★
```
