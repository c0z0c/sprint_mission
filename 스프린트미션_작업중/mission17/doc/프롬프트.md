## 💻 바이브 코딩 프롬프트 (VIBE Coding Prompt)

**제목:** ONNX MNIST 모델 기반 Streamlit 숫자 예측 웹 서비스 개발

**목표:** GitHub에서 제공하는 ONNX MNIST 모델을 활용하여, 사용자가 웹 캔버스에 그린 숫자를 실시간으로 예측하고 시각화하는 Streamlit 애플리케이션을 개발하고 도커 컨테이너로 배포합니다.

### 🎯 1단계: Streamlit UI 및 환경 구성

다음 라이브러리를 사용하여 Streamlit 애플리케이션의 기본 구조를 설정합니다.

1.  **필수 라이브러리 설치:** `streamlit`, `streamlit-drawable-canvas`, `onnxruntime`, `numpy`, `opencv-python`, `matplotlib`, `Pillow` (PIL)
2.  **UI 구성:**
    * **애플리케이션 제목:** "Streamlit ONNX MNIST 숫자 예측 서비스"
    * **입력 캔버스:** `streamlit_drawable_canvas`를 사용하여 캔버스 영역을 구현합니다.
        * 캔버스 크기: 가로/세로 약 200px (사용자 편의에 맞게 조정)
        * 브러시 색상: 검은색 (Black)
        * 배경 색상: 흰색 (White)
    * **레이아웃 구성:** `st.columns` 또는 `st.sidebar`를 활용하여 4개의 핵심 영역(`캔버스`, `전처리 이미지`, `추론 결과`, `이미지 저장소`)이 명확히 구분되도록 배치합니다.
3.  **세션 상태 관리:** 사용자가 그린 이미지 데이터와 예측 결과를 저장하기 위한 세션 상태 변수 (`st.session_state`)를 초기화합니다 (예: `st.session_state.history`).

### 🔧 2단계: 모델 로딩 및 이미지 처리/추론

#### 2-1. 모델 관리 및 캐싱

1.  **ONNX 모델 다운로드 함수:** GitHub ONNX Models 저장소에서 MNIST ONNX 모델 파일(`mnist-8.onnx` 또는 최신 버전)을 다운로드하는 함수를 작성합니다.
2.  **모델 로딩 및 캐싱:**
    * `@st.cache_resource` 데코레이터를 사용하여 ONNX 모델을 로드하고 ONNX Runtime 세션(InferenceSession)을 생성하는 함수를 구현합니다. 이는 세션 간 모델 로딩을 효율적으로 처리하기 위함입니다.
    * 함수는 다운로드된 모델 경로를 받아 `onnxruntime.InferenceSession` 객체를 반환해야 합니다.

3. 전처리 예
```
import numpy as np
import cv2

image = cv2.imread('input.png')
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
gray = cv2.resize(gray, (28,28)).astype(np.float32)/255
input = np.reshape(gray, (1,1,28,28)
```

#### 2-2. 이미지 전처리 함수

사용자가 캔버스에 그린 이미지 데이터를 ONNX 모델의 입력 사양($1 \times 1 \times 28 \times 28$, `float32`, 픽셀 값 정규화)에 맞게 변환하는 함수를 구현합니다.

* **입력:** `streamlit_drawable_canvas`에서 반환된 이미지 데이터 (Numpy 배열 또는 PIL Image).
* **처리 단계:**
    1.  **그레이스케일 변환:** 이미지를 흑백으로 변환합니다.
    2.  **크기 조정:** $28 \times 28$ 픽셀로 크기를 조정합니다.
    3.  **반전 및 정규화:** MNIST 모델은 일반적으로 **흰색 숫자**와 **검은색 배경**을 기대합니다.
        * 캔버스에서 그린 그림은 검은색 선/흰색 배경입니다. 모델 입력에 맞게 색상을 반전(Invert)합니다. (숫자 부분 픽셀 값이 높도록)
        * 픽셀 값을 $0.0$에서 $1.0$ 사이로 정규화합니다.
    4.  **형태 변경:** Numpy 배열 형태를 $(1, 1, 28, 28)$로 변경하고, 데이터 타입을 `np.float32`로 설정합니다.
* **출력:** 모델 입력에 적합한 전처리된 $1 \times 28 \times 28$ Numpy 배열.

#### 2-3. 모델 추론 함수

전처리된 이미지를 ONNX Runtime 세션에 입력하여 추론을 수행하고 결과를 반환하는 함수를 구현합니다.

* **입력:** ONNX Runtime 세션 객체, 전처리된 이미지 배열.
* **출력:** 예측 확률 배열 (로그 확률이면 $\text{softmax}$를 적용하여 확률로 변환), 예측된 레이블(가장 높은 확률을 가진 인덱스), 가장 높은 확률 값.

### 📊 3단계: 예측 결과 시각화 및 저장소 구현

1.  **전처리 이미지 표시:**
    * `2-2` 단계에서 생성된 $28 \times 28$ 전처리된 이미지를 `st.image`를 사용하여 시각적으로 표시합니다 (흑백 이미지로).
    * 사용자가 전처리 과정을 명확히 이해할 수 있도록 이미지 아래에 설명을 추가합니다.
2.  **모델 추론 결과 시각화:**
    * `2-3` 단계의 예측 확률(0-9)을 받아 Matplotlib 또는 Plotly를 사용하여 **막대 차트 (Bar Chart)**로 시각화합니다.
    * 가장 높은 확률을 가진 레이블을 시각적으로 강조 표시합니다.
    * **최종 예측:** 가장 높은 확률과 예측된 레이블을 큼직한 글씨로 표시합니다.
3.  **이미지 저장소 (History):**
    * 새로운 추론이 발생할 때마다, 원본 이미지 (캔버스 데이터), 예측된 레이블, 최고 확률 값을 `st.session_state.history`에 저장합니다.
    * 이 기록을 Streamlit UI의 별도 영역에 **표 (Table)** 형식으로 표시합니다. 각 항목에는 작은 썸네일 이미지, 예측 레이블, 확률을 포함합니다.
    * (선택 사항) 기록 삭제 버튼을 추가합니다.
