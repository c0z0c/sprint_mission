## 2. 데이터 전처리 및 모델링 결과 요약

### 2.1 데이터셋 개요
- **학습 데이터**: mission15_train.csv (7,000개 샘플)
- **테스트 데이터**: mission15_test.csv (3,000개 샘플)
- **타겟 변수**: Performance Index (10~100 범위의 학생 성취도 지수)

### 2.2 전처리 과정
1. **범주형 변수 처리**
   - `Extracurricular Activities` (Yes/No) → OneHotEncoding 적용
   - `drop='first'` 옵션으로 다중공선성 방지

2. **수치형 변수**
   - Hours Studied (공부 시간)
   - Previous Scores (이전 시험 점수)
   - Sleep Hours (수면 시간)
   - Sample Question Papers Practiced (연습한 모의고사 수)

3. **데이터 분할**
   - Train: 5,600개 (80%)
   - Validation: 1,400개 (20%)
   - random_state=42로 재현성 확보

### 2.3 모델링 및 성능
- **모델**: Linear Regression
- **파이프라인 구성**: ColumnTransformer (전처리) + LinearRegression (모델)
- **평가 지표**:
  - **RMSE**: 2.0103
  - **R-squared**: 0.9893

### 2.4 결과 분석
- 높은 R² 값(0.9893)으로 모델이 데이터의 98.93% 변동성을 설명
- RMSE 2.0103은 Performance Index 범위(10~100) 대비 약 2.2%의 오차
- 선형 회귀 모델이 학생 성적 예측에 매우 효과적임을 입증

### 2.5 모델 저장
- **파일명**: model.pkl
- **저장 방식**: joblib을 사용한 파이프라인 직렬화
- **저장 위치**: `/app/data/model.pkl` (컨테이너 내부) → 공유 볼륨을 통해 연구자 2에게 전달

## 3. 코드 아키텍처 도식 및 설명

### 3.1 전체 시스템 구조

```
┌─────────────────────────────────────────────────────────────┐
│                        Host System                           │
│                                                               │
│  ┌─────────────────────────────────────────────────────────┐│
│  │                    ./data (Bind Mount)                   ││
│  │  - mission15_train.csv                                   ││
│  │  - mission15_test.csv                                    ││
│  │  - model.pkl       (연구자 1 생성 → 연구자 2 사용)       ││
│  │  - result.csv      (연구자 2 생성)                       ││
│  └─────────────────────────────────────────────────────────┘│
│           ↑                                   ↑               │
│           │                                   │               │
│  ┌────────┴────────┐                ┌────────┴────────┐      │
│  │  mission15_train │                │mission15_inference│    │
│  │   (연구자 1)    │                │   (연구자 2)      │    │
│  ├─────────────────┤                ├──────────────────┤    │
│  │ python 3.11-slim│                │jupyter/scipy-note│    │
│  │                 │                │book:latest       │    │
│  │ - train_model.py│                │- inference.ipynb │    │
│  │ - requirements: │                │                  │    │
│  │   pandas 1.5.3  │                │  Port 8888:8888  │    │
│  │   scikit-learn  │                │                  │    │
│  │   1.2.2         │                │                  │    │
│  │   numpy 1.24.4  │                │                  │    │
│  │                 │                │                  │    │
│  │ Volume: ./data  │                │  Volume: ./data  │    │
│  │  → /app/data    │                │   → /app/data    │    │
│  └─────────────────┘                └──────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 워크플로우 설명

#### Phase 1: 연구자 1 - 모델 학습
1. **데이터 로드**: `/app/data/mission15_train.csv` 읽기
2. **전처리**: OneHotEncoding 적용 (범주형 변수)
3. **모델 학습**: LinearRegression 모델 훈련
4. **성능 평가**: RMSE 2.0103 달성
5. **모델 저장**: `/app/data/model.pkl` 저장
6. **컨테이너 종료**: 작업 완료 후 자동 종료 (`restart: "no"`)

#### Phase 2: 연구자 2 - 추론
1. **모델 로드**: 공유 볼륨에서 `/app/data/model.pkl` 읽기
2. **테스트 데이터 로드**: `/app/data/mission15_test.csv` 읽기
3. **추론 수행**: 로드한 모델로 예측
4. **결과 저장**: `/app/data/result.csv` 저장
5. **Jupyter Notebook**: 추론 과정을 `inference.ipynb`에 문서화

### 3.3 기술적 세부사항

#### 패키지 버전 관리
- **Python**: 3.11 (두 연구자 동일)
- **핵심 라이브러리 버전 통일**:
  - pandas 1.5.3
  - numpy 1.24.4
  - scikit-learn 1.2.2
  - joblib 1.2.0

#### 볼륨 공유 전략
- **Bind Mount 방식**: `./data` 디렉토리를 호스트와 두 컨테이너가 공유
- **연구자 1 → 연구자 2 데이터 흐름**:
  - 연구자 1이 `model.pkl` 생성 → 공유 볼륨에 저장
  - 연구자 2가 동일 볼륨에서 `model.pkl` 읽기
  - `depends_on` 설정으로 연구자 1 작업 완료 후 연구자 2 시작

#### Docker Compose 구성
```yaml
services:
  mission15_train:     # 연구자 1
    volumes:
      - ./data:/app/data
    command: python train_model.py
    restart: "no"

  mission15_inference: # 연구자 2
    volumes:
      - ./data:/app/data
    ports:
      - "8888:8888"
    depends_on:
      - mission15_train
```

### 3.4 실행 방법
```bash
# 전체 시스템 실행
docker-compose up --build

# Jupyter 접속
# 브라우저에서 http://localhost:8888 접속
```
