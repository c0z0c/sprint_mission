## 토크나이저 전체 구조 설계

### 1. 클래스 계층 구조

```
BaseTokenizer (추상 클래스)
    ├── JamoTokenizer (자소)
    ├── SyllableTokenizer (음절)
    └── MorphemeTokenizer (형태소)

BaseVocabulary (추상 클래스)
    ├── JamoVocabulary
    ├── SyllableVocabulary
    └── MorphemeVocabulary

DataPipeline (통합 파이프라인)
    - 토크나이저 선택
    - 어휘 사전 구축
    - 인덱싱
    - 패딩
    - Dataset/DataLoader 생성
```

---

## 클래스별 역할 정의

### 1. BaseTokenizer (추상 클래스)

**역할**: 모든 토크나이저의 공통 인터페이스

**메서드**
```python
- tokenize(text: str) -> List[str]
  # 텍스트 -> 토큰 리스트
  
- detokenize(tokens: List[str]) -> str
  # 토큰 리스트 -> 텍스트
  
- get_tokenizer_name() -> str
  # 토크나이저 이름 반환
```

---

### 2. JamoTokenizer (자소)

**역할**: 한글 자소 분해 및 복원

**주요 속성**
```python
- CHO: List[str]  # 초성 19개
- JUNG: List[str]  # 중성 21개
- JONG: List[str]  # 종성 28개 (빈 종성 포함)
```

**메서드**
```python
- _decompose_char(char: str) -> List[str]
  # 한글 1글자 -> 자소 리스트
  # "안" -> ["ㅇ", "ㅏ", "ㄴ"]
  
- _compose_jamos(jamos: List[str]) -> str
  # 자소 리스트 -> 한글
  # ["ㅇ", "ㅏ", "ㄴ"] -> "안"
  
- tokenize(text: str) -> List[str]
  # 전체 텍스트 분해
  # "안녕" -> ["ㅇ","ㅏ","ㄴ","ㄴ","ㅕ","ㅇ"]
  
- detokenize(tokens: List[str]) -> str
  # 토큰 -> 텍스트 복원
```

**에러 핸들링**
```python
- 한글이 아닌 문자: 그대로 유지
- 영어, 숫자, 구두점: 개별 토큰으로
- 알 수 없는 문자: <UNK> 처리 또는 건너뛰기
```

---

### 3. SyllableTokenizer (음절)

**역할**: 음절 단위 분리

**메서드**
```python
- tokenize(text: str) -> List[str]
  # "안녕하세요" -> ["안", "녕", "하", "세", "요"]
  # 영어: "hello" -> ["h", "e", "l", "l", "o"]
  
- detokenize(tokens: List[str]) -> str
  # 단순 결합
```

---

### 4. MorphemeTokenizer (형태소)

**역할**: 형태소 분리 (Mecab 사용)

**메서드**
```python
- __init__(self, use_mecab=True)
  # Mecab 설치 여부 확인
  
- tokenize(text: str) -> List[str]
  # Mecab 사용
  # "먹었습니다" -> ["먹", "었", "습니다"]
  
- detokenize(tokens: List[str]) -> str
  # 단순 결합 (완벽한 복원 어려움)
```

## Vocabulary 클래스

### 1. BaseVocabulary (추상 클래스)

**역할**: 어휘 사전 공통 인터페이스

**주요 속성**
```python
- token2idx: Dict[str, int]
- idx2token: Dict[int, str]
- PAD_IDX: int = 0
- UNK_IDX: int = 1
- SOS_IDX: int = 2
- EOS_IDX: int = 3
```

**메서드**
```python
- build_vocab(tokens_list: List[List[str]], min_freq=1)
  # 토큰 리스트에서 어휘 구축
  
- encode(tokens: List[str]) -> List[int]
  # 토큰 -> 인덱스
  
- decode(indices: List[int]) -> List[str]
  # 인덱스 -> 토큰
  
- __len__() -> int
  # 어휘 크기
  
- save(path: str)
  # 어휘 사전 저장
  
- load(path: str)
  # 어휘 사전 로드
```

---

### 2. JamoVocabulary

**역할**: 자소 기반 고정 어휘

**특징**
```python
- 고정 어휘 (약 150개)
- 초성 + 중성 + 종성 + 특수토큰 + 영어 + 숫자 + 구두점
- build_vocab() 호출 없이 초기화 시 자동 구축
```

---

### 3. SyllableVocabulary / MorphemeVocabulary

**역할**: 데이터 기반 동적 어휘

**특징**
```python
- build_vocab() 필수
- 빈도 기반 필터링
- min_freq, max_vocab_size 파라미터
```

---

## DataPipeline 클래스

**역할**: 전체 전처리 파이프라인 통합

**메서드**
```python
- __init__(self, tokenizer_type='jamo', lang='ko')
  # 'jamo', 'syllable', 'morpheme' 선택
  
- load_data(json_path: str) -> List[Dict]
  # JSON 로드
  
- tokenize_dataset(data: List[Dict]) -> List[Dict]
  # 전체 데이터 토큰화
  # 프로그레스바 포함
  
- build_vocabularies(tokenized_data)
  # 한국어/영어 어휘 사전 구축
  
- encode_dataset(tokenized_data) -> Tuple
  # 인덱싱
  
- create_dataloaders(encoded_data, batch_size, max_length)
  # TensorDataset, DataLoader 생성
  
```

### 2. 토큰화 (예시: 자소)

from tqdm import tqdm

# 토크나이저 생성
ko_tokenizer = JamoTokenizer()

    })

### 4. 인덱싱 및 패딩

```python
def pad_sequence(tokens, vocab, max_length, add_eos=True):
    """토큰을 인덱스로 변환하고 패딩"""
    indices = vocab.encode(tokens)
    
    if add_eos:
        indices.append(vocab.EOS_IDX)
    
    # 패딩 또는 트렁케이션
    if len(indices) > max_length:
        indices = indices[:max_length-1] + [vocab.EOS_IDX]
    else:
        indices += [vocab.PAD_IDX] * (max_length - len(indices))
    
    return indices

# 전체 데이터 처리
MAX_LENGTH = 200

encoded_train = []
for sample in tqdm(tokenized_train, desc="Encoding"):
    src = pad_sequence(sample['ko_tokens'], ko_vocab, MAX_LENGTH)
    
    # Target: Teacher Forcing용 input/output 분리
    tgt_tokens = sample['mt_tokens']
    tgt_input = [vocab.SOS_IDX] + vocab.encode(tgt_tokens)
    tgt_output = vocab.encode(tgt_tokens) + [vocab.EOS_IDX]
    
    tgt_input = pad_sequence(tgt_input, mt_vocab, MAX_LENGTH, add_eos=False)
    tgt_output = pad_sequence(tgt_output, mt_vocab, MAX_LENGTH, add_eos=False)
    
    encoded_train.append((src, tgt_input, tgt_output))
```

### 5. TensorDataset 및 DataLoader

```python
import torch
from torch.utils.data import TensorDataset, DataLoader

# 텐서 변환
src_tensors = torch.tensor([x[0] for x in encoded_train])
tgt_in_tensors = torch.tensor([x[1] for x in encoded_train])
tgt_out_tensors = torch.tensor([x[2] for x in encoded_train])

# TensorDataset
train_dataset = TensorDataset(src_tensors, tgt_in_tensors, tgt_out_tensors)

# DataLoader
train_loader = DataLoader(
    train_dataset,
    batch_size=128,
    shuffle=True,
    num_workers=2,
    pin_memory=True
)
```

## 클래스 인터페이스 요약

### 사용 예시

```python
# 1. 파이프라인 생성
pipeline = DataPipeline(tokenizer_type='jamo')

# 2. 데이터 로드
train_data = pipeline.load_data('clean_train.json')
valid_data = pipeline.load_data('clean_valid.json')

# 3. 토큰화
tokenized_train = pipeline.tokenize_dataset(train_data)
tokenized_valid = pipeline.tokenize_dataset(valid_data)

# 4. 어휘 구축
ko_vocab, mt_vocab = pipeline.build_vocabularies(tokenized_train)

# 5. 인코딩
encoded_train = pipeline.encode_dataset(tokenized_train, ko_vocab, mt_vocab)
encoded_valid = pipeline.encode_dataset(tokenized_valid, ko_vocab, mt_vocab)

# 6. DataLoader
train_loader, valid_loader = pipeline.create_dataloaders(
    encoded_train, encoded_valid,
    batch_size=128,
    max_length=200
)

```
